# 一键启动器设计文档

日期：2026-08-13

## 1. 背景与目标

为 GitHub 本周热门聊天应用新增“一键启动”：双击一个极小的 VBScript 文件，静默启动本地服务并自动打开浏览器，无需打开终端。

成功标准：

- 双击 `一键启动.vbs` 后，浏览器自动打开 `http://localhost:3000`。
- 全程无控制台/黑窗口。
- 文件尽量小（约 6 行 ASCII 代码），无第三方依赖。
- 服务已在运行时重复双击不报错，浏览器仍正常打开。

## 2. 方案

使用 VBScript（`WScript.Shell` + `FileSystemObject`），流程：

1. 用 `ScriptFullName` 定位脚本所在目录，并设为启动工作目录。
2. 隐藏窗口（window style 0）启动 `node server.js`。
3. 等待 2 秒，让服务完成监听。
4. 用系统默认浏览器打开 `http://localhost:3000`。

脚本内容为纯 ASCII，避免编码问题；文件名使用中文 `一键启动.vbs`。

## 3. 文件与交付

- 新建：项目根目录 `一键启动.vbs`。
- 交付：复制到 `outputs/github-trending-chat/` 并随 zip 打包。
- 在 README 中补充一行“一键启动”说明。

## 4. 行为与边界

- 若端口 3000 已被占用：第二个 node 进程因 EADDRINUSE 静默退出，浏览器仍正常打开，无副作用。
- 依赖 `node` 在 PATH 中（本机已满足）。
- 仅本地启动与打开本地页面，无网络请求、无系统级改动。

## 5. 验证方式

1. 用 `cscript //nologo` 运行脚本，确认语法与执行无报错。
2. 运行后确认 `http://localhost:3000` 可访问（HTTP 200）。
3. 确认没有可见控制台窗口残留（隐藏启动）。
4. 复跑既有测试套件，确保未破坏现有功能。
